===============================================================================
O QUE FOI FEITO
===============================================================================
Nova tabela project_versions guarda snapshots do payload INTEIRO de cada projeto.
  - kind='auto'   : gravado automaticamente após cada save bem-sucedido, COALESCIDO — no
                    máximo 1 por projeto a cada 5 min (AUTO_SNAPSHOT_WINDOW_MS). Só o projeto
                    ABERTO (currentProjectId) é snapshotado, não todo projeto que passou no merge.
  - kind='backup' : backup manual do usuário (botão "Salvar backup", com nome opcional). Nunca
                    é podado automaticamente.

Poda automática (pruneProjectVersions), só de autos:
  - TTL: autos com mais de 30 dias (AUTO_SNAPSHOT_TTL_DAYS) são apagados.
  - Retenção: mantém os 30 autos mais recentes por projeto (AUTO_SNAPSHOT_KEEP); o excedente é apagado.
  - Backups manuais NUNCA são podados.

Restaurar (restoreProjectVersion):
  - Antes de restaurar, grava um backup do estado ATUAL ("Antes de restaurar") — sempre dá pra voltar.
  - A restauração REUSA o mergeProjectsForSave do save normal: a versão entra com updatedAt novo
    (vence o merge por projeto), mas NÃO apaga conteúdo mais novo de outra pessoa (célula preenchida
    concorrente é preservada). Isso é intencional: prioriza não perder trabalho de colaboração.
    Trava/aprovação atuais são preservadas.
  - No editor avulso, reabre o projeto (projOpen) pra refletir o estado restaurado.

Degradação graciosa: se a tabela project_versions ainda não existir (42P01) ou der erro, a feature
some silenciosamente (_versionsTableMissing trava após o 1º erro) e nada mais quebra.
